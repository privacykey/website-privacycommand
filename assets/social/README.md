# Social share images

Drop two PNGs here before going live:

- `og-image.png` — 1200×630, used by Open Graph (Facebook, LinkedIn, iMessage, Slack, Discord)
- `twitter-card.png` — 1200×630, used by the Twitter / X large summary card

Both filenames are referenced from the HTML in `index.html`, `about.html`,
`privacy.html`, and `legal.html`. Until they exist, social shares will
render without a preview image — everything else still works.
